OOPs pillars
- Inheritance - It is mechanism where a new class can inherit the fields & methods 
of an exiting class which promotes code reusability.
- Polymorphism - Ability of an object to behave differently when context changes.
- Encapsulation - bundling of data and methods in a single unit. 
- Abstraction - hiding unnecessary details and showing only necessary features.
