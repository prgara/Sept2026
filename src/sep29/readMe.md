OOP ---- Object oriented programming

model your code the same way real life works - as objects that have data and behaviour.

properties (what it is) & behaviours (what it can do).

Java is OOP ??

class -- logical entity, template to create objects. does not hold any memory

non-primitive --- user defined data type. class

properties, fields, instance variables

object --- real instance of a class 

From one class, you can create as many objet as you want, each with their own data.


create a class Car which will have 3 fields, brand, model, color
create 2 objects of the car and give the value to the properties and print the same on the console.

Add 2 methods (displayInfo, playMusic)to class CAR and call that method in the main class.

rules for naming a class
- Always use PascalCase 
- Filename should match with class name
- cannot start with num or special character
- one public class in a file

method --- block of code which does one job/task
always have a return type.
